Temperature Monitor and Alarm Checker
What it does
This is a Python program that monitors the temperature of a machine. It collects five temperature readings and calculates the highest, lowest and average temperatures. It also warns the user when the temperature exceeds the safe limit.

How to run it
Install Python 3 and run:

python temperature_monitor.py

Sample output
Highest: 70.0 °C
Lowest: 40.0 °C
Average: 53.0 °C

WARNING! High temperature: 60.0 °C
WARNING! High temperature: 70.0 °C

Machine Status: WARNING
Temperature Trend: RISING
My own twist
I added a temperature trend checker. It checks whether the machine temperature is rising, falling or stable. I also added a machine status warning system.

What I learned
I learned how to use Python functions, loops, conditions and lists. I also learned how to calculate temperature values and handle invalid user input.
